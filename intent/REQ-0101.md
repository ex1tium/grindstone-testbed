# REQ-0101 — Slugs for titles

`testbed.text.slugify(title)` returns a URL slug: lowercase ASCII letters and digits, words joined by single hyphens, no leading or trailing hyphen; letters with diacritics map to their base letter; any other character separates words.

## AC-0101-1
Method: test · Required: yes

Given the title `"Grindstone: Proof, Not Promises!"`, when `slugify` is called, then it returns `"grindstone-proof-not-promises"`; and `slugify("  Ångström  ")` returns `"angstrom"`; and `slugify("---")` returns `""`.
